## Design Context

### Users
Salon owners, beauty professionals, and small service businesses managing appointments, staff, services, payments, and client relationships. The primary job is to see today's schedule quickly and move from insight to action without setup friction.

### Brand Personality
Warm, confident, polished. Bookora should feel reassuring and capable rather than corporate or overly playful. Language is concise, friendly, and action-oriented.

### Aesthetic Direction
Light, warm-neutral surfaces with Bookora's coral-red accent and deep navy text. Use clear left-aligned hierarchy, generous breathing room, gently rounded surfaces, and restrained shadows. Keep operational screens calmer and more focused than the marketing landing page. Avoid dark-mode-first, neon, dense admin-table, or generic dashboard styling.

### Implementation Defaults
Detected existing stack: Vite + React 18 + TypeScript, Tailwind v4, local shadcn-style primitives, Lucide icons, and Supabase Auth. Continue the existing CSS token system and component composition. No backend data model is available yet, so dashboard content should use clearly labeled mock data and honest placeholder states. Forms and table architecture remain lightweight until product requirements justify a dedicated library.
- Global UI typography: use 14px for body and operational page content; use 16px for page/header titles unless a marketing display heading explicitly needs a larger scale.

### Design Principles
- Establish hierarchy with spacing and weight before adding color.
- Keep one obvious primary action per screen, with secondary actions quiet and reversible.
- Use warm neutrals and a restrained coral accent for status and emphasis.
- Make empty and mock states teach the next useful action instead of pretending data exists.
- Design the core workflow for a busy owner scanning from a desktop sidebar or a narrow mobile viewport.
