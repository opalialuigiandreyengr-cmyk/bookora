## Design Context

### Users
Bookora PH is a mobile owner workspace for appointment-based service businesses, especially salon and beauty operators. Owners and staff use it throughout the day on phones to manage bookings, clients, payments, schedules, services, and business performance quickly.

### Brand Personality
Calm, capable, and welcoming. The product voice is concise and conversational. It should give busy operators confidence without feeling corporate, technical, or visually loud.

### Aesthetic Direction
Minimal, warm, and mobile-first. Use Space Grotesk, warm off-white neutrals, white surfaces, restrained coral accents, navy for strong selection states, fine borders, and gently rounded corners. Prefer clear hierarchy and open spacing over decorative effects, heavy shadows, gradients, glassmorphism, or dense card walls. Light mode is the established baseline.

### Implementation Defaults
Existing Expo SDK 58 / React Native 0.88 / React 19 app using Expo Router, Supabase, custom React Native components, StyleSheet-based styling, and shared tokens in `src/theme.ts`. Preserve the custom UI primitives and native form/state patterns already in the app. No external form, table, data-grid, or virtualization library is currently established; do not add one for ordinary mobile screens unless scale requires it.

### Design Principles
- Establish hierarchy with spacing, typography, and grouping before adding color.
- Keep one obvious primary action and make secondary actions quiet but discoverable.
- Optimize for fast one-handed scanning and generous touch targets on small phones.
- Reuse warm neutrals, coral accents, navy selection states, and the shared spacing/radius system.
- Prefer flat, purposeful sections over nested cards, decorative metrics, or redundant chrome.
